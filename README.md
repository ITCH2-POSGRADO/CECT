# CECT

Esta aplicación permite generar órdenes de transferencia, comprobaciones de gastos y órdenes de compra de forma sencilla. Los registros se guardan en un archivo SQLite (`data.db`) y pueden imprimirse desde la vista de cada orden.

## Uso

1. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecuta la aplicación:
   ```bash
   python app.py
   ```
3. Ingresa en `http://localhost:5000` para crear y consultar órdenes.
